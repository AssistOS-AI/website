Integrated toolchain

AssistOS uses several tools with distinct jobs. Explorer provides the workspace. AchillesAgentLib supplies agent-building components, and Ploinky runs packaged capabilities. AGISystem2 explores reasoning checks. Achilles CLI and the skill repositories support recurring development tasks. The links below describe each project; their maturity and integration vary.

Achilles IDE

Achilles IDE, also called AssistOS Explorer, is the web workspace for files, editing and agent tasks. It brings project work and the Copilot into the same interface.

Explore Achilles IDE →

Achilles AgentLib

AchillesAgentLib provides patterns for agent execution, skill coordination and memory. Developers can use these components to build agents and control how they call tools and other agents.

Explore AgentLib →

AGISystem2

AGISystem2 represents knowledge and tests statements against explicit logical constraints. It explores how these checks can support language-model output. The result depends on the inputs, the representation and the checks applied.

Explore AGISystem2 →

Ploinky

Ploinky packages tools and agents with their dependencies, then runs them in configured containers or sandboxes. It manages their startup and workspace access. The chosen runtime and permissions determine the isolation boundary.

Explore Ploinky →

Achilles CLI

Achilles CLI provides a command-line Copilot for workspace tasks, skills and calls to configured agents. Developers can use it in scripts and repeatable workflows. Consult its documentation for supported commands.

Explore Achilles CLI →

AchillesCopilotBasicSkills

AchillesCopilotBasicSkills contains reusable instructions for building and running skills. It supplies conventions that specialized agents can share.

Explore Basic Skills →
