Chapter 13: MRP-VM

MRP-VM (Multi-Role Pipeline Virtual Machine) represents a new paradigm for creating and configuring AI agents. Rather than building agents as monolithic applications, MRP-VM allows you to define agents as configurable systems that expose standard interfaces while encapsulating complex agentic architectures internally.

A New Way to Create Agents

MRP-VM agents expose standard interfaces to the outside world:

  • MCP (Model Context Protocol): A standardized protocol for tool and resource access that allows agents to interact with external systems in a consistent way.
  • OpenAI-Compatible APIs: Standard API endpoints that allow any OpenAI-compatible client to interact with MRP-VM agents, making them drop-in replacements for standard LLM calls.

Behind these standard interfaces, however, lies the ability to configure complex agentic systems. An MRP-VM agent can internally orchestrate multiple sub-agents, use different models for different tasks, maintain state across interactions, and execute sophisticated pipelines all while presenting a simple, standard API to the outside world.

Configuration Over Code

The key insight behind MRP-VM is that complex agent behavior should be configurable rather than requiring custom code. By defining agent roles, pipelines, and behaviors through configuration, users can:

  • Rapidly prototype new agent capabilities
  • Share and reuse agent configurations
  • Modify agent behavior without changing code
  • Maintain version control over agent configurations

This approach aligns with the broader AssistOS vision of specification-driven development, where the configuration of a system is the primary artifact and the system itself is a general-purpose executor of those specifications.
