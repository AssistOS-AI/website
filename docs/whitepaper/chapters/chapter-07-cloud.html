Chapter 7: Ploinky Cloud

Ploinky Cloud is a planned managed offering for people and organizations that want hosted Ploinky capabilities.

The service is in preparation. This whitepaper does not announce a launch date or price.

Planned services

  • Hosted agent environments and capacity management.
  • Infrastructure maintenance and security updates.
  • Tenant isolation and access controls.
  • Monitoring, backups and recovery.

Licensing

Ploinky's open-source runtime and the proposed cloud service have separate licensing arrangements. Ploinky Cloud is intended as a commercial offering, including licensing options for organizations that want to provide hosted Ploinky services.

For availability or licensing questions, contact the team.
