Chapter 1: Vision

AssistOS is an integrated ecosystem that bridges cutting-edge AI research with practical, production-ready tools. Born from Axiologic Research and accelerated through the EU-funded Achilles Project, AssistOS reimagines how humans and AI agents collaborate — not through patched legacy interfaces, but through a fundamentally new architecture built for the agentic era.

The Core Premise

The way we interact with computers is changing fundamentally. Large Language Models and AI agents are not incremental improvements — they represent a paradigm shift. Yet most existing interfaces and workflows are built on legacy patterns never designed for AI-native collaboration. AssistOS addresses this by creating an environment where specifications drive creation, pipelines ensure quality, and every output is the result of a validated, reproducible process.

The AssistOS Architecture

AssistOS is built around several interconnected layers, each addressing a critical aspect of AI-augmented work:

Achilles IDE (AssistOS Explorer) is the central workspace — a file explorer, code editor, and agent orchestrator in one. It integrates document management with OnlyOffice for collaborative editing, confidential file structures managed by DPU Agent, GitHub repository control, and the Achilles Copilot conversational interface. It is the place where specifications are written, pipelines configured, and results reviewed.

Ploinky provides the secure runtime environment — containerized agent isolation, sandboxed execution, and workspace management. It is the foundation that makes it safe to run untrusted agents and code.

AchillesAgentLib implements the cognitive architecture patterns — the building blocks for creating intelligent agents that can reason, plan, and execute complex tasks.

AGISystem2 provides formal reasoning and knowledge management — ensuring that agent outputs are not just plausible, but logically sound and verifiable.

Ploinky Wormhole is the decentralized communication protocol — replacing client-server messaging with direct peer-to-peer connections between agents. It enables modern email, chat, file transfer, and inter-organizational choreography without a central authority controlling your data.

Trustworthy AI Agent is the verification layer — inspecting datasets, models, and runtime behavior to produce auditable findings, risk reports, and compliance mapping to frameworks like EU AI Act, NIST AI RMF, and ISO/IEC 42001.

Security Guardian Agent is the intelligent security layer — watching code, dependencies, containers, models, configurations, network activity, user behavior, and agent behavior across the entire workspace.

LightDSU and DPU Agent form the data sovereignty stack — encrypted storage with verifiable provenance, controlled access through sandboxed execution, and interoperability with European Data Spaces.

ModelAutoResearcher Agent is the autonomous modeling laboratory — taking research objectives and delivering working, evaluated, documented models through a seven-phase cycle from data analysis to delivery.

NeuroVSA is a specialized neuro-symbolic research agent built on Vector Symbolic Architectures — systematically exploring which representation works for which problem class, accumulating validated experimental knowledge.

MRP-VM is the execution model that turns natural-language-derived tasks into executable, controlled programs with interpreters, policies, traces, validation, and persistent state.

AKU (Agentic Knowledge Units) is the context management system — organizing agent memory and knowledge in an explorable, user-controllable way through deterministic local indexing and BM25F search.

From Agentic Workflows to Build Pipelines

AI is transforming R&D activities across domains. Whether you are producing software, research papers, designs, or business plans, the process increasingly resembles a build system. AssistOS crystallizes this insight: automated pipelines should function as true Standard Operating Procedures — reproducible, auditable, and reliable. The specifications that feed these pipelines become the primary artifact. Crafting good specifications — telling AI what to build rather than how to build it — is the skill that matters most.

Decentralized Communication and Data Sovereignty

In an agentic world, the old client-server model becomes a bottleneck. Wormhole flips this: agents connect directly to each other through peer-to-peer channels. The server only facilitates introductions; content flows end-to-end encrypted. Combined with LightDSU's encrypted data units and DPU Agent's sandboxed execution, AssistOS ensures that data never leaves the control of its owner — whether that owner is a researcher, an organization, or an agent.

The AssistOS Vision

AssistOS is not just a collection of tools. It is a new way of working — an environment where humans specify intent and AI agents execute with precision, where creativity is amplified by automation, and where every output is the result of a validated, reproducible process. We are building the infrastructure for an agentic future: decentralized, trustworthy, and fundamentally human-centric.

The future of work is not about replacing humans with AI. It is about creating environments where humans specify intent, agents execute with precision, and every output is the result of a validated, reproducible process.
