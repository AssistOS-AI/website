Chapter 14: NeuroVSA — A Self-Improving Neuro-Symbolic Research Agent

NeuroVSA is a specialized AI research agent built on Vector Symbolic Architectures (VSA), Hyperdimensional Computing (HDC), and Holographic Reduced Representations (HRR). It receives problems in natural language, decomposes them into subproblems, selects suitable representational backends, runs experiments, validates results, and stores findings as Knowledge Units. Its central claim: no single representation is universally optimal — the right choice depends on the problem class.

Why VSA/HDC Matters

The dominant AI stack today relies on large neural models operating over dense floating-point tensors. This is powerful for language, perception, and generative modeling — but it is expensive, opaque, and poorly aligned with many forms of symbolic, procedural, legal, scientific, and biological reasoning.

VSA/HDC offers a different paradigm: information is represented by high-dimensional distributed vectors, and symbolic structure is encoded through algebraic operations — binding, bundling, permutation, cleanup, and similarity search. It is not a single model but a family of representations, each with different strengths.

The strategic implication is clear: a useful AI reasoning system should not search for one "best" representation. Following the No Free Lunch theorem, performance comes from exploiting problem structure. NeuroVSA treats representation choice as an empirical, domain-conditioned decision.

How NeuroVSA Works

NeuroVSA has six main subsystems:

Problem Interpreter uses LLMs and symbolic parsers to transform natural-language requests into structured problem descriptions, constraints, data types, expected outputs, and validation requirements.

Representation Registry stores available VSA/HDC/HRR backends, each described by its algebraic contract, cost profile, supported encoders, and known failure modes.

Experiment Engine runs controlled comparisons across representations, dimensions, encoders, noise models, cleanup memories, and task decompositions.

Validation Layer applies statistical tests, symbolic checks, baseline comparisons, ablations, and reproducibility tests.

Knowledge Unit Store persists every experiment, result, failure, benchmark, and validated heuristic as an auditable unit of knowledge.

Meta-Learning Planner learns which representation to try first for each problem class, when to split a problem, when to use LLMs, when to use exact symbolic tools, and when to reject a VSA approach.

The LLM is not the reasoning substrate. It is the linguistic front-end, methodological assistant, and hypothesis generator. The reasoning substrate is a dynamically selected combination of VSA/HDC backends, symbolic tools, statistical evaluators, and domain-specific engines.

A Portfolio of Representations

NeuroVSA maintains a portfolio of representation families, each with explicit operational contracts:

  • Binary Spatter Codes — fast symbolic binding, role-value records, provenance frames, local CPU execution.
  • MAP / bipolar HDC — robust bundling, classification, document encoding, biological feature aggregation.
  • Holographic Reduced Representations — approximate compositional structure, analogical representations, continuous vector binding.
  • Sparse binary representations — membership, routing, approximate filtering, large memory indexes.
  • Graph-VSA hybrids — explicit graph storage combined with VSA similarity for relation retrieval and provenance.
  • k-mer HDC / genomic hypervectors — sequence sketching, genome similarity, cohort comparison, biological indexing.
  • Ultrametric / hierarchical encodings — ontologies, taxonomies, legal categories, biological classifications.
  • Exact symbolic layer — rule execution, formal validation, policy compliance, GxP checks, legal constraints.

Many of these are partial representations — they deliberately sacrifice some classical VSA properties because those properties are not needed for the target problem. This is a valid design choice when done intentionally.

The Autoresearch Loop

NeuroVSA runs a continuous autoresearch cycle:

  1. Observe — receive user problems, benchmark failures, new datasets, new literature.
  2. Hypothesize — formulate representational hypotheses.
  3. Experiment — generate microbenchmarks, ablations, synthetic tasks, and domain-specific tests.
  4. Compare — evaluate against baselines, alternative representations, and LLM-only solutions.
  5. Validate — check reproducibility, statistical robustness, and sensitivity to parameters.
  6. Store — write Knowledge Units with traces, parameters, results, and conclusions.
  7. Promote — add validated architectures and selection rules to the active registry.
  8. Retire — deprecate weak heuristics and representations that repeatedly fail.

This is analogous to AutoML, but the search space is not conventional ML pipelines. It includes representational algebras, partial operation contracts, encoders, cleanup strategies, symbolic validators, and task decompositions.

Problem Classes

NeuroVSA is most promising for problems that are structured, noisy, compositional, and repeatedly queried:

  • Scientific literature analysis — encode claims, methods, hypotheses, evidence types, and citations; use VSA for clustering, contradiction candidates, and hypothesis routing.
  • Legal document analysis — encode parties, obligations, exceptions, conditions, and deadlines; use VSA for candidate retrieval and structural comparison, then symbolic validators for final interpretation.
  • Genomic sequence analysis — encode k-mers, variants, motifs, cohorts, and phenotypes; use k-mer HDC for compact similarity and cohort exploration.
  • Scientific workflow automation — encode protocols, variables, instruments, and observations; use Graph-VSA hybrids for traceable experiment comparison.
  • Security and monitoring — encode event streams, user actions, and policy violations; use HDC classification for fast local monitoring.

Fundamental Limits

NeuroVSA acknowledges fundamental limits and is designed to respect them:

  • Open-world limit. Absence of information does not mean falsity. NeuroVSA distinguishes between "true under local closure," "unknown in open world," and "requires external validation."
  • Frame problem. It is not enough to encode facts in hypervectors. The system must know what consequences are relevant. NeuroVSA uses explicit dependency graphs and symbolic validators.
  • Symbol grounding. Vectors are not meaning — they are operational instruments for manipulating representations anchored externally through measurements, protocols, ontologies, and human validation.
  • Capacity and noise. VSA is excellent for approximation, but should not be the sole mechanism for conclusions requiring exhaustiveness or formal certainty.
  • Encoder dependency. Performance often comes from the encoder, not the algebra. VSA amplifies the structure the encoder preserves; it does not recover structure lost at encoding.
  • No Free Lunch. No architecture is optimal across all problem classes. NeuroVSA learns: this problem class → this encoder → this representation → this validation.
  • Causal inference. VSA can detect associations, but not causality. NeuroVSA can organize and prioritize causal hypotheses, but does not certify them alone.

Vision

NeuroVSA is not a universal AGI substrate. It is a specialized autoresearch interpreter for representational reasoning — a system that becomes better not by vague adaptation, but by running experiments, comparing representations, validating results, and turning confirmed findings into reusable Knowledge Units. Its value lies in disciplined self-improvement: converting vague architectural intuition into measurable hypotheses, and accumulating an experimental atlas of what works, for what problem, under what conditions.
