Chapter 8: AI Research Agents

The ModelAutoResearcher Agent is Ploinky's autonomous modeling laboratory — a single agent that takes a research or product objective and delivers a working, evaluated, documented model. It encapsulates the entire cycle from raw data to installable artifact.

One Agent, Many Profiles

Instead of a collection of separate tools, ModelAutoResearcher Agent is an integrated entity with multiple internal profiles. You describe what you need — "classify these documents," "adapt an LLM for this domain," "find the best embedding model for these texts," "compare three approaches for information extraction" — and the agent handles the rest: data analysis, method selection, experiment planning, training, evaluation, and delivery.

The agent is pragmatic. For each requirement, it chooses the method that can produce a useful result given the real conditions of the workspace: available hardware, existing data, confidentiality constraints, time, budget, and the required level of evaluation.

The Full Cycle

The agent works in seven phases:

Objective interpretation. It receives a goal from a user or another agent and translates it into a concrete research plan.

Data analysis. It inspects available data — formats, sizes, missing values, duplicates, imbalances, label quality, leakage risks, and sensitivity. For text, it analyzes lengths, languages, styles, and categories. For tabular data, it checks distributions, correlations, and outliers. For graphs, it examines nodes, edges, and connectivity.

Experiment planning. It selects the working profile, base model, training or evaluation method, dataset structure, validation strategy, and success criteria. For LLMs, it may choose LoRA, QLoRA, or supervised fine-tuning. For tabular problems, it may select classical models, gradient boosting, or hybrid pipelines. For embeddings, it may choose zero-shot evaluation, contrastive adaptation, or fine-tuning.

Data preparation. It cleans, normalizes, transforms, deduplicates, splits, and documents the dataset. If data is insufficient, it activates Synthetic Data Lab to produce additional examples through larger LLMs, local rules, or specialized agents. Every generated example has provenance, schema, version, and filtering criteria.

Training or experimentation. It runs the appropriate local process: fine-tuning, LoRA adaptation, classifier training, embedding evaluation, tabular modeling, time-series analysis, or comparative benchmarking. It monitors resources, logs, errors, metrics, and early stopping.

Evaluation. It compares the resulting model against baselines and alternatives. Evaluation includes quantitative metrics, qualitative tests, representative examples, failure cases, and user-defined criteria.

Delivery. It produces final artifacts: model, adaptor, configuration, processed dataset, evaluation report, model card, inference instructions, limitation sheet, and extracted Knowledge Units.

Knowledge Accumulation

ModelAutoResearcher Agent does not only "learn" by updating model weights. It builds an explicit operational memory: training recipes, observations about datasets, efficient configurations, recurring failures, useful benchmarks, synthetic data prompts, filtering rules, and compatibilities between models and tasks.

After each experiment, the agent extracts Knowledge Units that can be validated automatically, approved by the user, or marked as experimental. These are saved at the workspace, folder, or subfolder level. At future experiments, the agent searches for relevant KUs and uses them for planning, avoiding past mistakes, and accelerating configuration.

Vision

The complete vision is for ModelAutoResearcher Agent to become the autonomous modeling laboratory of the Ploinky workspace: an agent capable of receiving a scientific or operational objective, investigating solutions, preparing data, producing models, comparing them rigorously, documenting them, and learning procedurally from every experiment. Not just a tool for researchers — a research partner that gets better with every project.
