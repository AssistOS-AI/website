Chapter 3: Simple Installation

One of the core design principles of AssistOS is accessibility. The entire ecosystem should be installable and runnable with minimal friction. We believe that powerful tools should not require complex setup procedures to get started.

Getting Started

The AssistOS environment is built on top of Ploinky, our secure agent deployment platform. Once Ploinky is installed on your system, the entire AssistOS environment can be initialized with a single command:

ploinky start explorer

This command handles the complete initialization process:

  • Setting up the workspace directory structure
  • Initializing the Achilles IDE (AssistOS Explorer)
  • Configuring default agent repositories
  • Establishing the local development environment

Prerequisites

Ploinky uses containerized environments for agent isolation, so you will need a container runtime installed:

  • Docker or Podman for full container isolation
  • Alternatively, on Linux, bubblewrap provides lightweight sandboxing without full containers
  • On macOS, seatbelt (sandbox-exec) offers similar lightweight isolation

Philosophy

This simplicity is intentional. We want researchers, designers, analysts, and professionals from any domain to be able to start working with AI agents without needing DevOps expertise. The complex infrastructure concerns container management, networking, security are handled automatically, so users can focus on what matters: specifying what they want to create and reviewing the results.

The installation process reflects our broader vision: AI tools should be as easy to start using as any modern application, while retaining the power and flexibility that technical users demand.
