Chapter 2: Achilles IDE and AssistOS Explorer

Achilles IDE provides the Explorer workspace in AssistOS. It brings file navigation, editing, agent configuration and task controls into a browser interface. Projects keep the work in one place as tools and models change.

Development background

The Achilles research project supported development from earlier AssistOS prototypes. The workspace combines existing editors and collaboration tools with agent controls. The integrations below have their own setup and maturity requirements.

Documents and access

The confidential document interface uses the DPU Agent to organize private files, shared files and secrets:

  • /Confidential/My Space holds personal folders and files.
  • /Confidential/Shared shows files shared with the user under the relevant access rules.
  • /Confidential/Secrets represents secrets as virtual files. The interface shows which entities have access, read or write permissions. Authorized changes propagate to entities with access.

The OnlyOffice integration opens .docx, .pptx and .xlsx files in the browser. It saves edits back to the confidential file system under the configured Secrets Agent access rules.

Repositories

Git controls support commits, pushes, pulls and branch management. A user can also assign repository work to an agent. Those actions need the same task scope and permission checks as other delegated work, especially before a push or publication.

WebMeet and the Copilot

WebMeet brings audio, video and chat into workspace groups and channels. The intended experience includes human colleagues and Robots as visible participants. A meeting room should have an explicit project context and access boundary.

Participants can ask a Robot to retrieve a source, edit a shared draft or run a task. Recording, transcription and post-meeting processing must follow the room's policy. A Robot's presence should make its role and access visible.

Shared blackboards

The agent-blackboard interface lets agents update a shared visual object. Supported objects include text, shapes, images, SVG diagrams, browser captures, clips, tables, lists, timers, inputs and simple animations. Common and individual boards support group discussion and private interactions.

AxiFace supplies SVG-based agent faces for chat and video interfaces. Applications control instances through HTML attributes, JavaScript or events. These faces represent interface state; they are not evidence of an agent's emotions or understanding.

Voice

Ploinky AudioAgent connects WebMeet audio to agent instances. It transcribes speech into messages and generates audio for an agent's reply. The described playback flow temporarily controls microphones to avoid echo.

Keep the project central

Explorer should make it clear which workspace, project and meeting room are active. A Robot result belongs beside the files it changes. Editors and plugins can evolve while the project keeps its artifacts and history.
