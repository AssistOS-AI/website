Chapter 4: Observability

Understanding what AI agents are doing, why they are doing it, and how well they are performing is essential for building trust and ensuring reliable outcomes. Observability in AssistOS goes beyond simple logging it provides deep insight into agent behavior, decision-making, and system health.

Provider Flexibility

The AssistOS system operates through AchillesAgentLib, which is designed to work with any LLM provider that offers OpenAI-compatible APIs. Additionally, the system supports direct integration with Google Gemini APIs and Anthropic APIs, giving users the freedom to choose the models that best fit their needs.

This provider-agnostic approach ensures that AssistOS is not locked into any single AI vendor. Users can switch between providers, use different models for different tasks, or even combine multiple providers within a single pipeline.

Soul Gateway

The recommended way to operate the AssistOS system is through the Soul Gateway component. Soul Gateway serves as the central observability and control plane for the entire ecosystem. It provides:

  • Unified API Management: A single point of configuration for all LLM provider connections, API keys, and model selections.
  • Request Routing: Intelligent routing of agent requests to the most appropriate model based on task type, cost considerations, and performance requirements.
  • Monitoring and Logging: Comprehensive tracking of all agent interactions, including prompts, responses, token usage, and execution times.
  • Cost Tracking: Visibility into API usage and costs across all providers and agents.
  • Health Checks: Real-time monitoring of provider availability and response quality.

Why Observability Matters

In an AI-augmented work environment, observability is not optional. When agents are executing build pipelines that produce important artifacts documents, designs, analyses users need to understand:

  • What decisions were made and why
  • Which models were used for which tasks
  • Whether the outputs meet quality standards
  • How to reproduce or modify the process

Soul Gateway makes all of this visible and controllable, turning the black box of AI execution into a transparent, auditable process.
