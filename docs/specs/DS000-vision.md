## Introduction

The AssistOS website introduces persistent virtual workers and shared workspaces, guides visitors to local installation, and connects readers to project research and component documentation.

## Core Content

The website must distinguish explanatory product vision from verified installation instructions and component contracts. Its workplace film is a concept presentation, not a running workspace or evidence that the depicted tasks have executed. Installation guidance must name the supported Ploinky commands and link the maintained component instructions. Research pages must preserve project documentation links and the chapter-based Whitepaper reader.

The published files under `docs/` are static assets. The website does not implement the agents, permissions, storage, or task execution described in linked product documentation. Archived articles remain historical material rather than the authority for current runtime behavior.
