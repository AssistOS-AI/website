AssistOS Website Documentation

Workplace film

The workplace film is the home page's browser-driven concept presentation about Sam's writing, research, and project work. Its scenes, captions, controls, progress, and transcript explain how persistent virtual workers fit a shared workspace. assets/js/workplace-film.js controls playback and optional browser speech. The film respects document visibility and reduced-motion preferences. Its scenes illustrate intended workflows; they do not run the depicted agents or modify a visitor's files.

Research embed

A research embed displays one component's external documentation inside research.html. The tool query key selects a fixed entry in script.js, which supplies the title, description, and iframe URL. Visitors can also open the original site through the external link. The remote project owns the documentation, and remote availability or iframe policy can affect the display. An unknown tool key keeps the directory visible instead of accepting an arbitrary URL.

Whitepaper reader

The Whitepaper reader displays research chapters fetched from whitepaper/chapters/. The full page and embedded version use the same chapter fragments, chapter identifiers, previous and next controls, and shareable URL hashes. Fragments are inserted into the host reader, so their relative links and anchors belong to that document context. The reader shows loading failures and guards against an older request replacing a newer selection. The chapter text explains project research rather than implementing its runtime.

Robot

In the website's concept narrative, a Robot is a persistent virtual worker configured with a role, a home, task history, and permitted workspace access. Sam's examples show writing, review, and research workers operating within a RoboTeam. The website explains those relationships through the film and Vision page. The linked runtime repositories define actual configuration, permission, execution, and storage contracts; the static site does not create Robots.

RoboTeam

A RoboTeam is the narrative's group of configured Robots working in a shared scope. The Books team separates drafting, review, and layout while Sam directs the work and approves results. The concept makes responsibility and shared context visible to visitors. Actual team ownership, task execution, and access rules belong to the component documentation reached through Research.
